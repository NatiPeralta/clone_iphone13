# 📱 Apple iPhone 13 Pro - Page Clone

Uma aplicação web interativa que recria a landing page oficial do **iPhone 13 Pro da Apple**, focando em minimalismo visual, fidelidade aos detalhes do produto, responsividade e alternância dinâmica entre temas **Dark** e **Light**.

<image src="img/iphone_green.png" alt="iPhone 13">

---

O projeto foi desenvolvido como atividade prática durante o curso **Formação Front-end** ministrado pelo portal **Hora de Codar** na Udemy.

---

## 🚀 Destaques do Projeto

- 🌓 **Tema Dark / Light:** Alternância de cores e estilos visuais acionada via JavaScript para simular diferentes experiências de navegação.
- 🎨 **Fidelidade Visual & UX:** Reprodução do estilo minimalista e elegante característico das páginas de produtos da Apple.
- 📐 **Layout Responsivo:** Adaptação fluida do grid, tipografia e imagens para diferentes resoluções (móvel, tablet e desktop).
- 🖼️ **Troca Dinâmica de Variantes:** Seleção de modelos/cores do aparelho com manipulação do DOM e atualização de imagens/estilos em tempo real.

---

## 🛠️️ Tecnologias Utilizadas

- **[HTML5](https://developer.mozilla.org/pt-BR/docs/Web/HTML):** Estruturação semântica e acessível das seções do produto.
- **[CSS3](https://developer.mozilla.org/pt-BR/docs/Web/CSS):** Variáveis CSS (Custom Properties), Flexbox, CSS Grid, transições suaves e media queries.
- **[JavaScript (ES6+)](https://developer.mozilla.org/pt-BR/docs/Web/JavaScript):** Lógica para alternância de tema, manipulação de classes e troca de imagens de exibição.
- **[Git & GitHub](https://github.com/):** Controle de versão do código.
